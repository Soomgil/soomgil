# 숨길 기능 명세

숨길은 사용자가 회원가입과 홈에서 장소 취향을 쌓고, 친구들과 여행방 투표를 마친 뒤 지도에서 함께 일정을 설계하는 협업 여행 서비스입니다.

## 사용자 유형

| 사용자 | 주요 목표 |
| :--- | :--- |
| 여행방 방장 | 여행방 생성, 멤버 초대, 일정 편집, 최종 루트 공유 |
| 여행방 멤버 | 스티커 투표, 일정 확인, 지도 공동 편집 |
| 커뮤니티 참여자 | 쓰레드 작성과 답글 참여 |

## 프론트 화면 범위

| 영역 | Vue 라우트 | 목적 |
| :--- | :--- | :--- |
| 랜딩 | `/` | 서비스 소개와 진입 CTA |
| 인증 | `/login`, `/register` | 로그인과 관광지 10개 필수 취향 수집 |
| 홈 | `/home` | 관광지 배경 탐색과 좋아요 수집 |
| 내 여행 | `/my-trips` | 여행방 목록과 관리 |
| 여행방 투표 | `/trips/:tripId/vote` | 첫 참여자의 스티커 투표 |
| 경로 설계 | `/trips/:tripId/route` | 투표 완료 후 지도 기반 일정 편집 |
| 커뮤니티 | `/community`, `/community/threads/:threadId` | 쓰레드와 답글 탐색 |
| 프로필 | `/mypage`, `/settings` | 사용자 프로필과 설정 |

## 백엔드 필요 기능

- 인증과 사용자 프로필.
- 여행방, 멤버, 권한.
- 회원가입·홈·투표의 장소 선호 이벤트와 projection.
- 여행방 투표, 일정, 경로와 지도 오브젝트 저장.
- 접속 상태, 커서와 오브젝트 잠금 실시간 동기화.
- AI 경로 초안과 추천 근거.
- 커뮤니티 쓰레드, 답글, 좋아요, 미디어.

## 현재 구현 기준

- 활성 제품은 `frontend/` Vue 앱입니다.
- `backend/`는 활성 Spring Boot 앱이며 담당자별 구현 진척은 backend TDD checklist에서 관리합니다.
- API 클라이언트는 `frontend/src/api/`에 있으며, 실제 backend 연결 시 이 경계를 기준으로 맞춥니다.

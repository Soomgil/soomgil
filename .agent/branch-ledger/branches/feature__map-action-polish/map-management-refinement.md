# 지도 관리 및 취향 UI 개선

- 관리·지도 테마 알약 버튼, 관리 버튼 불투명 흰 배경. 취향 보기 검정 글씨와 채워진 빨간 하트.
- 취향 패널 장소 목록 제거, 지도 마커 크기·외곽선·대비 강화.
- 기본 지도 최상단 및 저장된 선택이 없는 사용자의 초기값으로 지정. 기존 저장 선택 유지.
- 여행 기간을 한 카드로 표시하고 별도 From/To 범위 캘린더에서 편집. 기간 적용 후 관리창 저장으로 확정.
- 멤버 목록을 데스크톱 4열/모바일 3열의 작은 프로필 카드로 변경.
- 초대 링크는 서버 권한에 맞춰 방장에게 표시. 만료되거나 특정 사용자용 초대를 공용 링크로 재사용하지 않으며, 실패 재시도와 오래된 비동기 응답 차단 추가.
- 지도 동기화는 마지막 요청 대비 중심 30% 이동(경도 .002/위도 .0015 최소) 또는 범위 1.5배 초과/2/3 미만 변화에만 실행. 250ms 지연과 요청 취소 유지, 재조회 중 기존 결과 유지.

## 검증

- frontend 프로덕션 빌드 통과.
- 전체 테스트 440개 중 439개 통과 후 테마 순서에 의존하던 캐시 테스트 수정. 해당 캐시/관리창 테스트 16개 재실행 통과.
- harness:index 및 harness:check 통과.
- Playwright API fixture로 1440px/390px 취향 필터, 테마 순서, 캘린더 실제 날짜 클릭·적용, 9명 멤버 카드 및 생성 초대 링크 확인.
- 실제 초대 수락은 이번 UI QA에서 별도로 검증하지 않음.

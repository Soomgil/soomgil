# 멤버 프로필 및 설정 정리

- 멤버 목록 없는 TripSummary로 모달을 열었을 때 멤버 탭에서 getMembers를 조회하도록 수정했습니다. 요청 순번으로 이전 조회 결과가 다른 여행에 표시되지 않도록 합니다.
- 참여 ACTIVE 멤버의 프로필 이미지 표시, 미등록/이미지 실패 시 person 아이콘, 로딩/조회 실패/빈 상태와 재시도 제공.
- 여행 상태 설정 UI 제거. 정보 저장 시 기존 상태를 유지합니다.
- 삭제 안내 문구를 사용자 지정 문장 ‘영구적으로 여행 데이터를 삭제합니다.’로 변경했습니다.
- 모달 테스트 11개와 production build 통과. 브라우저 QA fixture 5명 프로필 및 멤버 목록 표시 확인. 마지막 문구 변경은 diff로 검증했습니다.

# 지도 여행방 바와 일정 전용 좌측 패널

- trip-header-card와 일차에 연동된 sidebarTheme 제거. 여행명/여행지/기간/동행자 최대 3명+N/투표/관리를 지도 작업영역 상단 바로 이동했습니다.
- 좌측은 일정 제목, 장소 수, 일차 탭, 스크롤 목록에 집중합니다. 기존 날짜/경로 색상 및 편집 기능 유지.
- 모바일은 여행명과 관리를 우선 표시하고 여행 정보 버튼으로 기간/동행자/투표를 펼칩니다.
- 지도 테스트 76개 및 production build 통과. 브라우저 fixture로 1440/390px 상단 바와 map-shell 비겹침, 가로 넘침 없음, 모바일 펼치기 확인.
- 브라우저 fixture는 레이아웃 검증이며 실제 지도 타일과 서버 일정 데이터 검증은 포함하지 않습니다.

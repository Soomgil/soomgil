# 내 여행 화이트 앨범

- 시안을 실제 MyTripsPage에 적용했습니다. 사용자 후속 요청에 따라 먹물 마스크를 사용하지 않고 4:3 사진과 화이트 테두리 카드로 변경했습니다.
- 검색창 오른쪽 새 여행 만들기, 최대 3명 프로필과 +N, 톱니바퀴 옵션(기존 설정/멤버 관리), 버튼 위 구분선을 적용했습니다.
- 9개씩 로컬 페이지네이션, 검색/필터 변경 시 첫 페이지 복귀. 목록 API가 검색을 지원하지 않으므로 서버 페이지를 순차 수집 후 검색/페이지네이션합니다. 여행 수가 많으면 초기 조회 요청이 늘어나는 제한이 있습니다.
- 프로필은 현재 화면 카드에 대해서만 기존 멤버 API로 조회하며 동시 요청 최대 4개, 실패/사진 미등록은 기본 아이콘을 표시합니다.
- 테스트: MyTripsPage 16개 통과(프로필 +N 및 페이지 이동/검색 초기화 포함), production build 통과.
- qa/check-trips.cjs: 12개 fixture로 9/3개 페이지 전환, 390px 가로 넘침 및 데스크톱/모바일 시각 검증.

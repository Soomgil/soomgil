# 화이트 먹 번짐 홈

## 확정 방향

- 사용자가 제공한 먹 번짐 참고 이미지와 최종 확인에 따라 화이트 한지 느낌의 배경에서 컬러 관광사진이 먹 자국 안에 드러나는 방향으로 변경했습니다.
- 기존 검은 갤러리 시안은 폐기했습니다. 검색창은 사용자 확인에 따라 재설계 전 캡슐/카테고리/그라데이션 버튼으로 복원했습니다.
- 관광공사 사진의 색상과 원본 파일은 변경하지 않습니다. 가장자리만 CSS luminance mask로 표현하고 원본 보기 링크를 둡니다.

## 구현

- 최소 크기 목표: 가로 사진 너비 720px, 세로 사진 높이 520px. 화면 경계와 원본 비율을 우선합니다. 기본은 원본 크기이며 목표보다 작은 사진만 확대합니다.
- 현재 조회된 사진들은 너비 940px입니다. 1440px 데스크톱에서 940×705 사진은 약 747×560px로 축소됩니다.
- ResizeObserver로 전시 공간 변경을 반영하고 이미지별 자연 크기를 기록합니다.
- InkWashBackdrop은 미세한 종이 질감을, ink-reveal-mask.png는 유기적인 가장자리를 제공합니다. 마스크는 imagegen 스킬의 기본 도구로 새로 생성한 자체 디자인 자산입니다.
- 생성 원본: C:/Users/kimgh/.codex/generated_images/01a0a524-cd4f-7710-b3fc-d812e207fcdb/exec-4598e195-74cc-4431-be97-4ee6a0421c49.png
- 둘러보기는 사진의 placeName, 없으면 regionName으로 장소 검색을 엽니다. 둘 다 없으면 버튼을 숨깁니다. 장소 식별자는 추정하지 않습니다.
- 기존 홈 검색 값과 실제 검색 결과 탭 불일치를 수정했습니다: 계획→여행, 여행지→장소, 커뮤니티→여행기, 유저→사용자.

## 검증

- 기능 및 크기 테스트를 먼저 실패 확인 후 구현했습니다.
- frontend 전체 60개 테스트 파일, 424개 테스트 통과.
- production 빌드 통과.
- 실제 localhost:5173 Docker 화면을 Playwright로 확인했습니다. 인증/기타 API만 fixture이고 수상작은 실제 로컬 API입니다.
- 1440px 데스크톱, 390px 모바일 스크린샷 확인, 320/768/1024px 가로 넘침 없음.
- 200×300 테스트 이미지는 데스크톱에서 347×520, 좁은 모바일에서 200×300으로 비율과 경계를 유지합니다.
- QA PNG는 로컬 검토용이며 Git에서 제외합니다.

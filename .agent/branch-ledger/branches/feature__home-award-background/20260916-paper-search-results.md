# 홈 검색 단순화와 검색 결과 테마 통일

## 요청 및 변경

- 사용자가 화이트 먹 번짐 홈을 승인하고 홈 검색창 위 5개 버튼 제거와 검색 결과 디자인 통일을 요청했습니다.
- 홈 카테고리/선택 상태를 제거했습니다. 전체 검색으로 이동하며 사진의 둘러보기는 기존 장소 필터 진입을 유지합니다.
- 검색 결과는 동일한 paper AppShell과 InkWashBackdrop, 기존 생성 마스크를 재사용합니다. 별도 이미지 생성은 없습니다.
- 큰 마케팅 헤더를 검색어 제목/표시 결과 수로 변경했습니다. 결과 필터는 아래쪽 텍스트 버튼으로 유지합니다.
- 검색창 스타일을 paper-search.css로 공유합니다. 장소 상세 모달도 화이트/초록/명조로 맞췄습니다.
- 결과 목록은 기존 API의 섹션별 제한 4개를 유지합니다. 표시 결과 수를 전체 검색 건수로 표현하지 않습니다.

## 검증

- 먼저 홈 버튼 제거와 검색어 제목 테스트 실패를 확인한 후 구현했습니다.
- 홈 검색 이동, 결과 필터, 장소 상세 조회, 재검색 실패/빈 결과 테스트가 통과했습니다.
- qa/check-search.cjs로 Docker localhost:5173에서 홈→검색 결과→필터→상세 열기를 확인했습니다.
- 브라우저 QA는 실제 수상작 이미지를 쓰되 검색 결과와 인증/장소 상세 API는 fixture입니다.
- 데스크톱 및 모바일 스크린샷을 확인했습니다. 320/390/768/1024px 가로 넘침이 없습니다.
- QA 이미지: home-simple-search.png, search-desktop.png, search-mobile.png, search-detail.png (Git 제외).

## 운영

- feature/home-award-background에서 작업합니다. 원래 frontend 작업 폴더는 변경하지 않습니다.
- 기존 qa/start-home-preview.ps1로 frontend만 재빌드합니다.

## 후속 디자인 조정

- 검색 캡슐과 파란 검색 버튼은 핵심 행동을 식별하기 쉬워 유지했습니다.
- 자세히 보기 버튼은 44px 이상 높이의 초록 윤곽선과 화살표로 변경했습니다.
- 사용자 카드는 56px 원형 프로필과 이름/팔로워 수를 가로 배치하고 화면에 따라 3/2/1열로 표시합니다.
- home-artwork-footer의 사진 너비 바인딩을 제거해 최대 940px의 독립된 영역으로 유지합니다.
- check-footer.cjs에서 수정 전 가로/세로 사진 전환 시 x=250→520으로 이동하는 실패를 재현했고, 수정 후 x=250, width=940 유지가 통과했습니다.
- 후속 변경 관련 테스트 12개와 production build 통과. 이전 전체 테스트 427개 통과.
- 사용자 카드의 긴 이름과 320/390/1440px 화면도 브라우저 fixture로 확인했습니다.

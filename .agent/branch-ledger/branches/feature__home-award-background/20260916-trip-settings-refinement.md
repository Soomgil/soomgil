# 여행 카드 탐색 및 설정 모달 후속

- 계획 보기 버튼 제거. 카드 본문/빈 공간은 Route 지도 화면, 투표와 톱니바퀴 버튼은 전파 중지 후 개별 동작합니다.
- 동행자 오른쪽에 투표, 톱니바퀴 순서로 배치합니다.
- 설정 모달을 화이트/먹빛 초록으로 정리하고 회녹색 헤더+탭, 흰색 스크롤 본문, 하단 저장 영역으로 구분했습니다. settings-trip-name 제거.
- 사용자 확정 기준: 지난 여행은 종료일 경과 또는 ARCHIVED, 미정은 그 외 ACTIVE 중 시작/종료일 누락, 진행 중은 날짜가 모두 있는 ACTIVE. 기존 보관 탭 제거.
- 목록 전체 상태를 조회해 날짜 기반 지난 여행이 누락되지 않도록 했습니다. 9개씩 로컬 페이지네이션 유지.
- MyTripsPage 및 TripSettingsModal 테스트 28개 통과. 데스크톱/390px 모달 및 페이지네이션 브라우저 QA 통과.

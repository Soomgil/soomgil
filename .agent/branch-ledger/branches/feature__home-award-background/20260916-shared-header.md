# 공통 화이트 헤더

- 사용자 요청: 내 여행 구성 제안 및 모든 탭 헤더 통일.
- 내 여행 본문은 구성 제안 단계이며 변경하지 않았습니다. 여행 앨범형 카드, 기존 전체/진행 중/보관됨 필터, 새 여행 만들기 중심 구성을 제안합니다.
- AppHeader 자체에 paper 스타일을 기본 적용해 직접 사용하는 SwipePage와 AppShell 페이지가 같은 배경/간격/색상을 갖습니다.
- 선택된 메뉴는 연한 초록색으로 표시합니다. 경로 편집 작업공간의 별도 반응형 동작은 유지합니다.
- 헤더 테스트 5개, production build, harness 검사 통과.
- qa/check-headers.cjs로 홈/내 여행/취향 수집/커뮤니티/기록 5개 경로의 1440px 및 390px 헤더 배경/높이/패딩 일치를 확인했습니다. API는 QA fixture를 사용했습니다.

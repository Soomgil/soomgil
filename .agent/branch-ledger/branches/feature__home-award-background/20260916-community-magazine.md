# 커뮤니티 화이트 매거진

- 인기와 최신 영역을 유지하고, 좋아요 상위 3개를 데스크톱 폴라로이드 3열/모바일 가로 스냅으로 표시합니다. 기간 한정 인기라는 표현은 사용하지 않습니다.
- 테이프 장식 제거, 1~1.2도 기울기와 얕은 그림자, 작성자 프로필/반응 수 표시.
- 최신은 사진 4:3, 반듯한 3/2/1열 피드, 작성일, 검색 오른쪽 글쓰기 버튼, 9개씩 기존 로컬 페이지네이션을 적용합니다.
- 사진 없는 글은 실제 여행 사진으로 오인할 대체 이미지를 목록에 사용하지 않습니다. 인기 영역은 아이콘, 최신은 텍스트 중심 카드입니다.
- 기존 API 조회 100개 제한과 상세/좋아요/작성 동작 유지. 전체 서비스 게시물의 무제한 페이지네이션은 아닙니다.
- 커뮤니티 API 연동 테스트 7개, production build 통과. QA fixture로 인기 3개/최신 9개/검색 빈 상태/320·390·768px 가로 넘침 확인.
- QA 이미지 community-desktop.png 및 community-mobile.png는 예시 글과 실제 수상작 사진을 사용하는 검증 데이터입니다.

# 지도 스카이 테마

- RoutePage에 route-sky-theme.css를 추가해 공통 색상 변수와 일정/장소/협업/팝업 패널 배경, 테두리, 선택 상태를 스카이 팔레트로 맞췄습니다.
- html:not(.dark) 범위에만 적용합니다. 일차/경로/추천 등급 등 의미가 있는 색상은 변경하지 않습니다.
- 크기/배치/지도 스타일/업무 로직은 변경하지 않았습니다.
- 이전 요청으로 제거한 여행 상태 설정을 기대하던 RoutePage 테스트를 현재 요구사항에 맞게 수정했습니다.
- production build 통과. 지도 컴포넌트 모킹 기반 RoutePage 기능 테스트로 회귀를 확인하며 실제 지도 타일/네트워크 연동 시각 검증은 별도입니다.

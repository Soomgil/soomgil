# develop 전체와 README의 main 릴리즈 검증

## 배경

- 사용자는 README 개편과 함께 develop에 누적된 기존 변경 전체를 main에 반영하도록 명시적으로 요청했다.
- 기준 develop: 7d4783af4e2f00de79bc3d401b2462595447e25a. 당시 main보다 236개 커밋 앞서 있었으며, 기존 기능·계약·설정·서브모듈 변경을 포함한다.
- 기존 태그 v1.0.0 다음 기능 릴리즈를 release/v1.1.0으로 준비한다. main/develop에 직접 push하지 않고 PR로 병합한다.

- develop 전체 및 README의 뱃지·PPTX 화면·오프닝·아키텍처 이미지를 main에 통합한다.
- Windows에서 Vitest가 public 절대 이미지 URL을 모듈로 변환해 랜딩페이지 테스트를 불러오지 못하는 문제를 발견했다.
- frontend PR https://github.com/Soomgil/soomgil-frontend/pull/51: Vitest 설정에서 includeAbsolute=false로 public URL을 보존했다. 제품 Vue 코드와 실제 Vite 설정은 변경하지 않았다.
- 릴리즈의 frontend 포인터를 병합 커밋 662be63bc5ffd27f7a82cc50ee086f941c0ed78a로 갱신한다.
- backend 포인터는 검증 대상 c3f8632574e7aaddb8e135b3fa185f0d0f0a64f7을 사용한다.

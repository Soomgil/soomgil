# 기존 제품 이미지

랜딩·로그인 배경과 장소 검색·투표의 기존 사진은 제품에 있던 이미지를 유지했습니다. 커뮤니티에는 위 수상작 중 차밭·사계해변·동백숲·오름 사진을 사용했습니다. 11번 지도는 사용자 제공 PDF 9쪽에서 추출한 기존 화면입니다. 수상작으로 출처가 확인된 사진만 수상작으로 표기했습니다. 지도 저작자 표시는 원본 화면에 보존했습니다.
